# Contributing

Contributions are welcome.

## How to contribute

1. Fork the repository.
2. Create a topic branch.
3. Add or improve documentation in the appropriate section.
4. Keep examples PowerShell-focused and concise.
5. Commit the change and open a pull request.

## Style notes

- Prefer clear headings and short sections.
- Group new content by functional area.
- Keep examples executable and realistic.
- Avoid mixing unrelated topics in one document.
